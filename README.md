# Visca Cup ⚽

A small practice project built using **Vue 3 + TypeScript + Vite**.

## 📦 Tech Stack

- Vue 3
- TypeScript
- Vite

## 📖 About

**Visca Cup** is a simple sports contest application designed as a practice project.

The idea is:

- Users will answer **random and varied sports-related questions**
- Each correct answer increases the user's **score**
- The **highest score** will be displayed on the screen
